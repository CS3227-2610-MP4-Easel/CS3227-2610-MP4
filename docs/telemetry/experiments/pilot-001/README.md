## Question counts

Question counts in these CSVs exclude status updates (decision C~15 of the `w7-pm-plan-flow` branch state): a turn that only says the agent is waiting for a subagent is not a question. Older run logs that stored such lines as questions are read with those rows left out, which lowers `lite` r1, `lite` r2, `full` r1 and `full` r2 by one each compared with the counts reported before the fix. `lite` r3 keeps 2: its second message is a long gate stop that asks for approval, so it stays a question.
