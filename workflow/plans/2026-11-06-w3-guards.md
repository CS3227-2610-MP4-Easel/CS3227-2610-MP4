## Scope
**Goal:** fill W2's guard slot with the AD-25 pipeline: sanitise, redact and flag untrusted input, wrap it in a random per-call boundary after fitting with a fixed security suffix, and reject unsafe model output.
**In scope:** F1-F7, N1-N5.
**Non-goals:** blocking on injection (§7, SD2); redacting long digit runs (SD4); the security corpus and authorisation tests (W11); live corpus runs (W17); `AiContext` (W6); feature prompts and schemas (W7-W9); rendering (`web`); any frozen-contract change (AD-11); client-controlled settings (guardrails, A-07).
**Risk tier:** High - every rule ID has a positive and a negative unit test; the close-out runs the Attacker and Tester lenses on the branch diff.
