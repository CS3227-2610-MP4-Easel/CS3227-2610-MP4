**In scope:** F1 to F7, N1 to N5; `run`, `Sessions` plus `regenerate`, providers and mock registry, guard slot, budget block and windows, `isInTransaction` in `@agile/db`, usage queries.
**Non-goals:** W3's guards (SD1); feature prompts and mock responses (SD2); usage endpoints 56-57 (W15, SD3); the result cache (AD-18, off); the SoCLaaS budget endpoint (SD7); final model choice (AD-23b); scheduled cleanup (AD-06); frozen-interface changes (AD-11); the Known Gap **A few users can use up the global AI windows**.
**Risk tier:** High. Test-first throughout; integration tests run against real Postgres 16 and must not be left skipped at close-out; the branch gets the Attacker and Tester lenses before Gate 3.

**Commands** (from `STATE.md` §2 and `workflow/config.json`): `<TEST>` = `npm test` (its `pretest` runs `prisma generate`; the script runs every test file through `scripts/discover-tests.mjs` with `tests/setup-auth-env.ts`). `<BUILD>` = `npm run typecheck`, then `npm run lint`, then `npm --workspace @agile/db run prisma:validate`. Fit (intended shape; conventions.md § Token budget):
```ts
const render = (s: Section) => `## ${s.name}\n${s.text}`;
const est = (text: string) => Math.ceil([...text].length / MODELS[model].tokenRatio);
// 1. statics: any over its own budget, or their sum over maxPromptTokens -> throw STATIC_SECTION_OVER_BUDGET:<name>
// 2. non-static over own budget: binary-search the largest code-point prefix with est(render(prefix)) <= budgetTokens
// 3. while total > maxPromptTokens: drop the non-static with the highest priority number (ties: later index)
// 4. system = statics by (priority, index) joined "\n\n"; user = the rest the same way
```
Rules the snippet leaves implicit:
- `STATIC_SECTION_OVER_BUDGET:<name>` names the first static section (list order) over its own budget; when only the total is over, the last static section in list order.
- A non-static section whose rendered header alone exceeds its budget is dropped (0 in `sectionTokens`) rather than cut.
- `sectionTokens[name]` = `est(render(section))` after fitting; `estimatedPromptTokens` = `est(system) + est(user)` (separators included in each message).
- Cost and reservation use integer arithmetic: `Math.ceil((promptTokens * priceIn + completionTokens * priceOut) / 1_000_000)`, so 104 stays 104 (E32).

```ts
const state = await db.llmGatewayState.findUnique({ where: { key: "budget" } });
// blockedUntil: a valid ISO instant in state.value.blockedUntil, else null (missing row, null or malformed)
const until = blockedUntil(state); const now = clock.now();

const sum = Number((await db.llmCall.aggregate({ _sum: { costMicrousd: true }, where: { env: settings.tier, createdAt: { gte: startOfUtcDay(now) } } }))._sum.costMicrousd ?? 0n);

await db.llmGatewayState.upsert({ where: { key: "budget" }, create: { key: "budget", value: { blockedUntil: next.toISOString() } }, update: { value: { blockedUntil: next.toISOString() } } });
```
