## Rules that apply
- Routes parse/compose/map only; actor comes from principal.
- Endpoint 48 has policy LEAD member plus ProposalService session-owner check.
- List routes return shared page envelopes; all mutations use service transaction boundaries.
- Hidden resources map to 404; stale version to 409 CONFLICT_VERSION; state/authorization conflicts to 409 CONFLICT_STATE; malformed input to 422.
