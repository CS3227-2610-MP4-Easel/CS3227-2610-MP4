## Objective
Implement core-owned sprint list/create/patch/start/close/delete plus progress and velocity. Every mutation locks project first, uses RepeatableRead bounded retries, validates exact task sets and writes task events atomically.

## Rules that apply
- Sprint transitions: PLANNED → ACTIVE → CLOSED; only PLANNED can be deleted.
- Sprint dates are inclusive; overlap includes boundary dates; archived projects are not writable.
- Close requires exact live non-DONE source-task set, max 1,000 carry-over entries, and BACKLOG or same-project PLANNED target.
- Progress is `(pointsDone / pointsTotal) * 100`, zero when total is zero; velocity is newest three closed sprints by `endDate DESC, id ASC`.

## Contract
[contract] Export a `SprintService` with actor-aware list/create/patch/start/close/remove. Return stable domain errors `NOT_FOUND`, `CONFLICT_VERSION`, `CONFLICT_STATE`, `VALIDATION_FAILED`. Close writes `SPRINT_CHANGED` events and completed points in one transaction. Progress returns `{ pointsTotal, pointsDone, percent, unestimatedTasks, velocity[] }`, with percent 0 when total is zero and otherwise `(pointsDone / pointsTotal) * 100`.

## Edge cases assigned
| ID | Scenario | Expected behaviour |
|---|---|---|
| E1 | End date precedes start date | 422 and no row. |
| E2 | Dates overlap another live sprint, including a boundary date | 422 and no mutation. |
| E3 | Mutation targets ACTIVE, CLOSED or deleted sprint | 409 `CONFLICT_STATE` and no mutation. |
| E4 | Two starts race | At most one ACTIVE sprint commits; loser gets 409. |
| E5–E9 | Close/delete input, retry and assigned-task cases | Exact validation/state error and atomic task/event outcome. |
| E10 | No points or closed sprints | Zero totals/percent and empty velocity. |
| E11 | Equal sprint end dates | `endDate DESC, id ASC` is deterministic. |
| E21 | Deleted/live sprints across pages | Only live rows return with stable per-request page metadata. |
| E18 | Event insertion fails during close | Entire close rolls back. |
| E22 | One of four points done | Percent is 25. |
| E26 | Carry-over task is outside source sprint/project | 422 with no changes. |
