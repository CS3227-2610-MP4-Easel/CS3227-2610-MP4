## Objective

Rewrite the production runbook so it contains no manual Prisma command. ## Rules that apply

- AD-32: the owner does not run production Prisma or the migration wrapper locally.
- The only production migration entry point is the protected CI workflow’s wrapper command.
- No secret values, URLs with credentials, hook URL, or response bodies enter evidence.

## Contract

The runbook contains `node --import tsx scripts/w13/migrate-production.mjs` only as the CI action description, never as a manual owner command, and contains no `prisma migrate deploy` production instruction. It requires redacted confirmation that Vercel Production Branch auto-deploy is disabled before release. Migration target/manifest/checksum failure, command failure, or hook failure prevents a passing release outcome.
