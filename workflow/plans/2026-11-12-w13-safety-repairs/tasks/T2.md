# T2: Workflow checker contracts

**Delivers:** Baseline workflow validation plus an explicit production workflow contract | **Satisfies:** F4, F5, E5, E8-E9 | **Depends on:** - | **Wave:** 1 | **Weight:** complex | **Review:** full (Attacker; CI policy boundary)

## Expected state

- `scripts/check-workflows.mjs` has a filename-based exception for `.github/workflows/w13-production.yml`.
- `tests/process-security/workflow-security.test.ts` tests generic workflow trigger, permission, and environment rejection.
- `.github/workflows/w13-production.yml` is currently absent.

## Objective

Remove path-only privilege. Every workflow receives baseline safety checks. Add an explicit exported production contract for the committed workflow path that requires push-only `main`, no pull-request or dispatch trigger, protected `production` environment, serialized concurrency, pinned approved Actions, checkout of `github.sha`, migration before Deploy Hook, and no Vercel API token.

## Rules that apply

- A future file with the former filename must not receive privilege merely from its name.
- Baseline checker errors remain safe and deterministic; do not print secrets.
- The production contract is a deliberate content/path check, not a generic exemption.

## Contract

`validateWorkflowText(text, pins, file)` applies baseline checks to all files and preserves the existing `string[]` error API. `validateProductionWorkflowContract(text, file)` also returns `string[]` and rejects any file other than `.github/workflows/w13-production.yml`, any pull-request/dispatch trigger, non-`main` push, missing `environment: production`, missing `concurrency.group=production`, `cancel-in-progress` not false, unapproved actions, wrong checkout ref, direct Prisma migration, or deployment trigger before the wrapper. `validateWorkflowDirectory()` must invoke this contract for the committed production path after baseline validation; the CLI and existing tests continue to consume strings.

**Edge cases assigned**

| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E8 | Former filename or another filename uses privileged triggers/environment | Baseline or production-contract validation rejects it unless the exact committed production contract passes. |
| E9 | Production workflow uses unpinned/unapproved Actions | Checker rejects it. |
