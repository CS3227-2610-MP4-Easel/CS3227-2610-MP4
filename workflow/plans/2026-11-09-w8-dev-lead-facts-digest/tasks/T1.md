## Expected state

## Objective

Create the role workspace and pure facts/forecast functions. The functions take narrow database ports,
capture one clock instant, produce the frozen `Facts` shape, and return both facts and a SHA-256 hash
whose input excludes `asOf`.

## Rules that apply

- F1/N1/N3: live/active target predicates apply to every joined row; facts never call the gateway.
- SD5: endpoint facts may later use caller-member overload, while this task exposes a target-only mode for digests.
- No raw SQL, migrations, or contract-schema edits.

## Contract

- `pointsTotal` is the sum of estimated live task points; `pointsDone` sums live `DONE` task points;
  `pointsRemaining` sums live non-`DONE` task points; unestimated tasks increase only
  `unestimatedTasks`. Every task, sprint, checkpoint, epic, member and user join keeps the active
  target-project predicate.
- Use the newest three closed sprints or fewer, ordered `endDate DESC,id ASC`. `completedPoints` is
  the points completed in that sprint. `avgVelocity` is their unrounded JavaScript arithmetic mean,
  or null without history. Average inclusive sprint length rounds exact half-days upward.
- `projectedCompletionDate` is null when average velocity is null or zero; otherwise it is the
  Asia/Singapore calendar date after `ceil(pointsRemaining / avgVelocity)` average-length sprints.
  A checkpoint uses the same formula over live non-DONE points in its live epics; no velocity is
  `UNKNOWN`, otherwise after target date is `AT_RISK` and on/before is `ON_TRACK`.
- Caller facts group open assigned points only across the caller's active member projects, retaining
  a person only with points in at least two such projects. Target-only digest facts include only the
  target project and retain a person with any open points. Both use the last-three-sprint rule for
  nullable average completed points.
- Sort checkpoints `targetDate ASC,id ASC`, overload users `userId ASC`, nested projects `projectId ASC`.
- Hash `Facts` without `asOf` as recursively key-sorted UTF-8 JSON, lowercase SHA-256 hex.
- Average velocity uses unrounded JavaScript arithmetic; average sprint length rounds half-days upward.

**Edge cases assigned**

| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E1 | No tasks or history | zero/empty values; null average and dates |
| E2 | Unestimated tasks | counted but never contribute points |
| E3-E5 | Short/zero history and empty checkpoint | fewer than three sprints remain newest-first; zero/null average gives null projections and `UNKNOWN`; an empty checkpoint is zero points and `ON_TRACK` |
| E6,E25 | caller/member or mixed-project fixture | caller mode excludes non-member projects; target mode has only target rows |
