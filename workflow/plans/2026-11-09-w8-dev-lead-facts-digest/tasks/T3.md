**Delivers:** endpoints 42, 44 and 45 wired through policy/API composition | **Satisfies:** F2,F4,F6,F7,N1,N4,E7,E8,E17,E18,E26,E28 | **Depends on:** T1,T2 | **Wave:** 3 | **Weight:** complex | **Review:** full (role policy, membership and protected AI mutation)

> Implement this task only. Read T1/T2 handovers first; stop if route service names do not match.

## Expected state

- T1 provides caller-member facts; T2 provides lead runtime flow methods.
- `src/be/api/src/routes/index.ts` exposes W5 route composition, and `core-composition.ts` owns resource resolvers.
- `src/be/core/src/resolvers.ts` has a project-operation registry that does not yet include `PROJECT_FACTS_READ`.

## Objective

Add thin lead route factories and wire them into the existing production composition. Policy map remains
the only role gate; extend core resource resolution for endpoint 42/44/45 project ids and convert only
typed lead-flow failures to existing API errors.

## Rules that apply

- AD-55: handlers receive already-authorized principals and never duplicate role checks.
- Protected requests authenticate/authorize before parsing; hidden/non-member targets remain 404.
- Body is JSON `{}` only; non-JSON is 415, invalid body/path is 422 with no service/model/session work.
- `DigestSchema` response includes `cached`; endpoint 45 always returns false.

## Contract

- Endpoint 42 is `GET /api/projects/{id}/facts`: PM/DEV_LEAD member, caller-member facts, no gateway/session.
- Endpoint 44 is `POST /api/lead/projects/{id}/digests`: DEV_LEAD member, exact JSON object `{}` only; map `AI_BUSY` to 429 with decimal-seconds `Retry-After`; degraded result remains schema-valid 200 with `cached: false`.
- Endpoint 45 is `GET /api/lead/projects/{id}/digests/latest`: DEV_LEAD member, latest target digest or 404; its response always has `cached: false`.
- Route registration uses `FactsSchema`/`DigestSchema`; add `PROJECT_FACTS_READ`, `LEAD_DIGEST_CREATE`, and `LEAD_DIGEST_LATEST_READ` to core project resolution.
