**`src/be/api/src/dev-composition.ts`** [contract]
- `createDevComposition(auth: AuthRuntime)` (uncached; tests use it) and `getDevComposition(auth)` (cached per `auth` in a `WeakMap`, production uses it): `core = createCore({ db: auth.db, archivedMembership: auth.lookupArchivedMembership })` (core's own `requireMember`, which rejects archived projects), `projects = createProjects(auth.db, { requireMember: core.requireMember, archivedMembership: auth.lookupArchivedMembership })`, then `createDevRuntime({ db: auth.db, requireMember: core.requireMember, members: projects.members, lookupArchivedMembership: auth.lookupArchivedMembership })`; returns `{ resolvers, routes: createDevRoutes(runtime) }`.
- `withDevComposition(core: CoreComposition, dev): CoreComposition` - `resolveResource = (op, request, tx) => dev.resolvers[op] ? dev.resolvers[op](request) : core.resolveResource(op, request, tx)`; `routes = [...core.routes, ...dev.routes]`; `requireMember` unchanged.
