## Objective
The endpoint-51 logic for one (project, developer, date): build the window, assemble context, return the stored row on an unchanged input hash, otherwise get a session (regenerate or open), call `run` at most once, fall back to code-built content on model failure, and upsert in one short transaction.

## Rules that apply
- No `run` inside a transaction; at most one `run` per request; flow takes everything through `deps`.
- Unchanged hash returns the stored row even when it is degraded (contracts row 51, AD-06).
- The 5-regeneration cap is never a reason to open a new session; only a session that is gone or unusable is.
- Code-built lines pass the output guard; the session stays OPEN (W16 closes it).
- Error propagation as in T7: `NotMember` from `assembleWith` → `Error("NOT_FOUND")`; `ContextScopeViolation`, `CONTEXT_SOURCE_*`, `LLM_CALL_IN_TRANSACTION`, `INVALID_LLM_CALL` propagate.

## Contract
```ts
export type StandupFlowDeps = {
  db: unknown; write: DevWriteDeps; now(): Date; ai: Pick<AiContextWith, "assembleWith">; gateway: LlmGateway;
  sessions: { open(i: { feature: "DEV_STANDUP"; userId: string; projectId: string }): Promise<string>; regenerate(sessionId: string, userId: string): Promise<void> };
  recordCacheHit(i: CacheHitInput): Promise<void>; sanitiseFlag(text: string): boolean;
  checkLine(line: string): boolean; // true when checkOutput(line, { kind: "text", maxChars: 300 }, { boundary: randomBytes(8).toString("hex"), secrets: [] }).ok
};
export async function generateStandup(deps, caller: { userId: string; role: "DEVELOPER" }, projectId: string, date: string | undefined): Promise<Standup>; // [contract]
```
1. `date = assertValidStandupDate(date, now)` (→ `DevError("VALIDATION_FAILED", 422)`). `window = standupActivityWindowFor(date, now)`.
2. Window empty (`from >= to`) → `assembled = { sections: [], provenance: [] }` with no `assembleWith`; else `assembleWith(caller, "DEV_STANDUP", projectId, { window })`.
3. `inputHash = standupInputHash(date, assembled.sections, assembled.provenance)`; `row = findStandup(db, projectId, caller.userId, date)`.
4. `row?.inputHash === inputHash` → `recordCacheHit({ feature: "DEV_STANDUP", caller, sessionId: row.sessionId, projectId, inputHash, promptVersion: STANDUP_PROMPT_VERSION })`; return `toStandup(row, true)`. No session change, no call.
5. Session: no row → `open`; row → `regenerate(row.sessionId, userId)`, and on `Error("NOT_FOUND")` or `Error("CONFLICT_STATE")` → `open`. `SessionCapReached` (by `name`) from either → `DevError("RATE_LIMITED", 429, retryAfterSeconds)`.
6. Every assembled section's text trims to empty (or none) → content `{ yesterday: [], today: [], blockers: [] }`, `degraded: false`, no `run`.
7. Else one `run({ feature: "DEV_STANDUP", caller, sessionId, projectId, sections: withStatics(STANDUP_STATIC, assembled.sections), output: { kind: "json", schema: StandupOutputSchema }, inputHash: sectionsInputHash(those sections) })`. `ok` → model content. `AI_BUSY` → `DevError("AI_BUSY", 429, retryAfterSeconds, LOCAL_LIMIT_DETAILS)` (architecture §8: every AI endpoint's `AI_BUSY` carries the `LOCAL_LIMIT` reason), nothing stored. `ROLE_DENIED` → `DevError("INTERNAL_ERROR", 500)`. Any other code, or a thrown `Error("LLM_CALL_FAILED")` → code-built, `degraded: true`.
8. Code-built: `yesterday` = the `"task-events"` section text split on `"\n"`, empty lines dropped, first 12, each cut to 300 UTF-16 units (one fewer if that splits a surrogate pair); `today = []`; `blockers` = the `"blocked-tasks"` section the same way. A line with `!checkLine(line)` becomes `"(line hidden: unsafe text)"` and sets `hidden`.
9. `flagged` = (`run` ok and `result.flagged`) OR `sanitiseFlag(text)` for any assembled section OR `summaryFlagged(db, userId, provenance ids with type "ITEM_SUMMARY")` OR `hidden`.
10. `upsertStandup(write, userId, projectId, date, { content, inputHash, degraded, flagged, sessionId })` (NOT_FOUND/CONFLICT_STATE/other errors propagate); return `toStandup(row, false)`.

**Edge cases assigned**
| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E26 | Second call, unchanged input | `cached: true`, same `version`, no `run`, no `regenerate`, one `recordCacheHit` |
| E27 | New task event after a standup | new hash; `regenerate` on the stored session; `version` +1 |
| E28 | Stored session at 5 regenerations, still OPEN (`regenerate` throws `SessionCapReached`) | 429 `RATE_LIMITED` with `Retry-After`; no `open`; row unchanged |
| E29 | Stored session abandoned (`regenerate` throws `CONFLICT_STATE`) | `open` called; the new session id stored on the row |
| E30 | No summaries, events or blocked tasks | a session is opened; no `run`; all lists `[]`; `degraded: false` |
| E31 | `AI_DISABLED`, `AI_UNAVAILABLE`, `REQUEST_REFUSED`, `BLOCKED_INPUT`, or `run` throws `LLM_CALL_FAILED` | 200, `degraded: true`, code-built content |
| E32 | Stored degraded row, unchanged input | `cached: true`; the stored degraded row; no `run` |
| E33 | `AI_BUSY` | 429 with `Retry-After` and `details: [{ field: "reason", message: "LOCAL_LIMIT" }]`; no row written or changed |
| E56 | `open` throws `SessionCapReached` (fourth open standup in 30 min, or 21st session of the day) | 429 `RATE_LIMITED` with `Retry-After` |

| E71 | Degraded path; a blocked reason holds `<a href="x">` | that line is `"(line hidden: unsafe text)"`; `flagged: true` |
| E76 | `now` is 00:00 SGT exactly and `date` is tomorrow | no `assembleWith`; content all `[]` |
