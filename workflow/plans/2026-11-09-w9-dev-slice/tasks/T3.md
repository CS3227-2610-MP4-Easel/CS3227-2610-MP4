## Rules that apply
- Source scan rule 1 - `gateway-binding.ts` is the only file in `src/be/dev/src` that imports `@agile/llm-gateway`; it has no relative imports and imports nothing else from `@agile/*` except `@agile/contracts` and `@agile/ai-context`.

- Archived beats non-member inside the seam: an archived project gives `CONFLICT_STATE` before membership is checked.

**`src/be/dev/src/store/writable.ts`** [contract]:
```ts
export type DevWriteDeps = { db: MutationTransaction; requireMember(userId: string, projectId: string): Promise<void> };
export async function assertDevWriteAllowed(tx: unknown, userId: string, projectId: string, requireMember: DevWriteDeps["requireMember"]): Promise<void>;
export async function inDevWrite<T>(deps: DevWriteDeps, userId: string, projectId: string, mutate: (tx: unknown) => Promise<T>): Promise<T>;
```
- `inDevWrite` = `inMutationTransaction(deps.db, lock, recheck, mutate)` where `lock(tx)` = `lockProjectForMutation(tx, projectId)`, rethrowing any error whose `code === "P2025"` as `new Error("CONFLICT_STATE")`; `recheck(tx)` = `assertDevWriteAllowed(tx, userId, projectId, deps.requireMember)`.
- `assertDevWriteAllowed`: `tx.project.findFirst({ where: { id: projectId }, select: { status: true } })`; `null` or status not `"ACTIVE"` → `throw new Error("CONFLICT_STATE")`. Then `await requireMember(userId, projectId)`; a `NotMember` (from `@agile/contracts`) or an `Error("NOT_FOUND")` → `throw new Error("NOT_FOUND")`; anything else is rethrown.
- `src/be/dev/src/index.ts` exports `inDevWrite`, `assertDevWriteAllowed`, `type DevWriteDeps` (T9 adds the rest).

**Edge cases assigned**
| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E40 (seam) | Project archived before the write transaction | `inDevWrite` rejects with `CONFLICT_STATE`; `mutate` never runs |
| E62/E63 (seam) | Caller removed from the project before the write transaction | rejects with `NOT_FOUND`; `mutate` never runs |
| - | Lock update throws a Prisma error with `code: "P2025"` | rejects with `CONFLICT_STATE` |
| - | Serialization failure (`code: "40001"`) on the first attempt | retried by `inMutationTransaction`; the second attempt's result is returned |
| - | `mutate` throws | the error propagates; the fake transaction records a rollback |
