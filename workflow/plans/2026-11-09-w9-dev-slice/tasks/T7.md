## Objective
The endpoint-50 logic: read the caller's items, answer cached ones from `item_summaries`, fail uncached ones dated before today's window, and for the rest open or reuse one `DEV_SUMMARY` session, assemble context, call `run` once, map the answer by row number and insert the new summaries in one short transaction after the call.

## Rules that apply
- No `run` inside a transaction (N2): all reads happen before, the single insert after.
- At most one `run` per request (N4).
- The flow file takes everything through `deps` (no import of `@agile/db`, `@prisma/*` or the binding); types may come from `@agile/contracts` and `@agile/ai-context`.
- `ContextScopeViolation`, `CONTEXT_SOURCE_*`, `LLM_CALL_IN_TRANSACTION`, `INVALID_LLM_CALL`, and a session `NOT_FOUND`/`CONFLICT_STATE` thrown by `run` propagate (500); never caught for retry. `NotMember` from `assembleWith` → `Error("NOT_FOUND")`.
- No item text, one-liner or prompt in any error, log or `DevError`.

## Contract
```ts
export type SummaryFlowDeps = {
  db: unknown; write: DevWriteDeps; key: { guardVersion: string; promptVersion: string }; now(): Date;
  ai: Pick<AiContextWith, "assembleWith">; gateway: LlmGateway; sessions: { openOrReuse(i: { feature: "DEV_SUMMARY"; userId: string; projectId: string }): Promise<string> };
  recordCacheHit(i: CacheHitInput): Promise<void>; sanitiseFlag(text: string): boolean;
};
export async function generateSummaries(deps, caller: { userId: string; role: "DEVELOPER" }, projectId: string, itemIds: string[]): Promise<{ summaries: { itemId: string; oneLiner: string; cached: boolean }[]; failed: string[] }>; // [contract]
```
`CacheHitInput` is a local type with the same shape as the gateway's (`feature, caller, sessionId, projectId, inputHash, promptVersion`).
1. `items = loadOwnItems(...)` (NOT_FOUND → propagates: 404, no session, no call). `current = currentSummaries(db, items, key)`.
2. Cached ids → `summaries` with `cached: true` (whatever their date). Uncached with `occurredAt < windowStart` → `failed` (`windowStart = standupActivityWindowFor(defaultStandupDate(now), now).from`). `left` = the other uncached ids, request order.
3. `left` empty: if any id was cached, one `recordCacheHit({ feature: "DEV_SUMMARY", caller, sessionId: null, projectId, inputHash: sha256Hex(JSON.stringify(cached.map(i => [i.id, i.contentHash]))), promptVersion: SUMMARY_PROMPT_VERSION })`. No session, no call. Return.
4. `sessionId = openOrReuse(...)`; `SessionCapReached` (match by `name === "SessionCapReached"`) → `DevError("RATE_LIMITED", 429, err.retryAfterSeconds)`.
5. `assembled = ai.assembleWith(caller, "DEV_SUMMARY", projectId, { itemIds: left })`.
6. `sections = withStatics(SUMMARY_STATIC, assembled.sections)`; one `gateway.run({ feature: "DEV_SUMMARY", caller, sessionId, projectId, sections, output: { kind: "json", schema: SummaryOutputSchema }, inputHash: sectionsInputHash(sections) })`; thrown `Error("LLM_CALL_FAILED")` → `DevError("AI_UNAVAILABLE", 503)`.
7. Not ok: `AI_BUSY` → `DevError("AI_BUSY", 429, retryAfterSeconds, LOCAL_LIMIT_DETAILS)`; `AI_UNAVAILABLE` → `DevError("AI_UNAVAILABLE", 503)`; `AI_DISABLED` → `DevError("AI_DISABLED", 503)`; `BLOCKED_INPUT` → `DevError("VALIDATION_FAILED", 422)`; `ROLE_DENIED` → `DevError("INTERNAL_ERROR", 500)`; `REQUEST_REFUSED` → every `left` id into `failed`, nothing inserted, return 200 shape.
8. Ok: for each entry in order, `n` must be 1..`left.length` and not used before, and `oneLiner.trim()` non-empty; then `left[n-1]` gets it. Unmapped `left` ids → `failed`. New rows: `contentHash` = the hash read in step 1, the stored and returned `oneLiner` is the trimmed text, `flagged = item.flagged || sanitiseFlag(oneLiner)`, `callId = result.callId`; `insertSummaries(...)` once (NOT_FOUND / CONFLICT_STATE propagate).
9. If any id was cached in a request that also called the model: one `recordCacheHit` as in step 3, after the insert.
Both lists are returned in request order.

**Edge cases assigned**
| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E15 | One id belongs to another developer in the same project | `NOT_FOUND` for the whole request; no session, no call |

| E17 | Model returns only `n=1` of 3 | item 1 summarised; items 2-3 in `failed` |
| E18 | Model output fails the schema or the output guard | `DevError AI_UNAVAILABLE 503`; nothing inserted |
| E19 | Mock answers `{"refusal":true}` | 200 shape; every uncached id in `failed` |
| E21 | Uncached item dated before the window | in `failed`; not in the section |
| E22 | `GUARD_VERSION` changes | old summary not current; the item is summarised again |
| E53 | Gateway returns `AI_BUSY` | `DevError AI_BUSY 429`, `retryAfterSeconds` = the gateway value, `details: [{ field: "reason", message: "LOCAL_LIMIT" }]`; nothing inserted |
| E54 | `openOrReuse` throws `SessionCapReached` | `DevError RATE_LIMITED 429` with its `retryAfterSeconds`; no `run` |
| E55 | `AI_DISABLED`; `BLOCKED_INPUT`; `ROLE_DENIED` | 503 `AI_DISABLED`; 422 `VALIDATION_FAILED`; 500 |
| E60 | `assembleWith` throws `NotMember` | `NOT_FOUND`; no `run`; no write |
| E62 | Caller removed after `run`, before the insert | `NOT_FOUND` (from `insertSummaries`); no row |
| E65 | Model returns `n=0`, `n=4` (3 requested), `n=1` twice, `n=2` with `"  "` | item 1 = the first `n=1` text; items 2-3 in `failed` |
| E67 | Unknown random UUID vs another developer's id | identical `NOT_FOUND` |
| E68 | Mock one-liner holds `<a href=` or `http://x` | `DevError AI_UNAVAILABLE 503` |
| E72 | An item body holds a line break followed by `n=2 COMMIT x` | the row is one line; the mock returns one entry per requested item |
| E73 | 10 items with 2,000-character bodies | each row cut to 900 code points; one `run`; result `truncated: false` |
| E75 | Two batches within 30 min | both call `openOrReuse` (reuse itself is T2's, tested there) |
| N2 | Any successful uncached request | `isInTransaction()` (from `@agile/db`) is false inside `run`; exactly one transaction committed |
