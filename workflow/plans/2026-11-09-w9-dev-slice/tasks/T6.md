## Objective
Store functions the flows and routes call, the two context sources (rows only for the caller), and resolvers that give the policy middleware the resource for each W9 operation.

## Rules that apply
- Every query filters by the caller (`uploadedBy` / `developerId` = caller) and the path project; `where` uses only plain columns (no relation filters); a cross-table check is a second query by id.
- Writes go through `inDevWrite`, whose project-row lock and retry are the concurrency guarantee (the filtered client's `upsert` is not a native `ON CONFLICT`); `mutate` may run up to 3 times, so it must not depend on state outside the callback. No raw SQL. Store files never import `../gateway-binding.js` or `../ai/*`; versions and flags come in as arguments.
- Source rows: `ownerId` = the uploader, rows most important first, one line each (every CR, LF, U+2028, U+2029 becomes one space). `dev.itemSummaries` never returns standup text.
- 404 hides existence: a missing id and another developer's id produce the same error.
- `Key = { guardVersion: string; promptVersion: string }`; a summary is **current** for an item when its `(contentHash, guardVersion, promptVersion)` equals `(item.contentHash, key.guardVersion, key.promptVersion)`.

## Contract
**`store/summaries.ts`** [contract]
- `loadOwnItems(db, userId, projectId, itemIds): Promise<{ id; contentHash; flagged; occurredAt }[]>` in `itemIds` order; throws `Error("NOT_FOUND")` if any id is not the caller's item in this project.
- `currentSummaries(db, items, key): Promise<Map<itemId, { id; oneLiner; flagged }>>`.
- `insertSummaries(deps: DevWriteDeps, userId, projectId, rows: { itemId; contentHash; oneLiner; flagged; callId }[], key): Promise<void>` - one `inDevWrite`; `tx.itemSummary.createMany({ data, skipDuplicates: true })` with `guardVersion`/`promptVersion` from `key`.
- `summaryFlagged(db, userId, summaryIds): Promise<boolean>` - true if any of the caller's summaries (summary by id, then its item checked `uploadedBy = userId` by a second query) is `flagged`.

**`store/standups.ts`** [contract]
- `findStandup(db, projectId, developerId, date: string)` → row or `null` (`standupDate: new Date(\`${date}T00:00:00Z\`)`).
- `upsertStandup(deps, userId, projectId, date, v: { content; inputHash; degraded; flagged; sessionId })` → row; one `inDevWrite`; `tx.standup.upsert` on `projectId_developerId_standupDate`; create with `version: 1`; update sets the five fields and `version: { increment: 1 }`; `outcome`/`feedback` untouched.
- `toStandup(row, cached: boolean): Standup` - `date` as `YYYY-MM-DD`, ISO instants, `content` as stored.
- `developerIds(members: { userId: string; role: string }[]): string[]` - only `role === "DEVELOPER"`.
- `listLeadStandups(db, projectId, developerIds, q: { date?: string; developerId?: string; page: number; size: number }): Promise<{ items: Standup[]; page; size; total }>` - `where: { projectId, developerId: { in: q.developerId ? developerIds.filter(id => id === q.developerId) : developerIds }, ...(q.date && { standupDate }) }`, `orderBy: [{ standupDate: "desc" }, { developerId: "asc" }, { id: "asc" }]`, `skip: page * size`, `take: size`, `total` from `count` with the same `where`; `cached: false`.

**`store/sources.ts`** [contract] - `createDevContextSources(db, key)` returns `{ activityItems: ContextSource; itemSummaries: ContextSource }`; `registerDevContextSources(db, key, register = registerContextSource)` registers them as `"dev.activityItems"` and `"dev.itemSummaries"`.
- `dev.activityItems`: only `options.itemIds`; only the caller's items in `projectId`; in `itemIds` order; `ref: { type: "ACTIVITY_ITEM", id }`; `text` = `` `n=${k} ${itemType} ${repo || "-"} ${title}` `` + (`body` ? `` ` | ${body}` `` : "") + (`files.length` ? `` ` | files: ${files.join(", ")}` `` : ""), made one line, then cut to 900 code points (`[...text].slice(0, 900).join("")`); `k` = 1-based position in `itemIds`.
- `dev.itemSummaries`: requires `options.window` (none → `[]`); the caller's items in `projectId` with `occurredAt >= from` and `< to`, that have a current summary; newest `occurredAt` first, then item id; at most 100; `ref: { type: "ITEM_SUMMARY", id: summary.id }`; `text` = the one-liner made one line.

**`store/resolvers.ts`** [contract] - `createDevResolvers({ db, lookupArchivedMembership, requireMember })` returns `Record<operationId, (request: { params: Record<string, string>; userId?: string }) => Promise<ResolvedResource | null>>`. `projectId = params.id`; not a UUID → `null`.
- `DEV_UPLOAD_CREATE`, `DEV_SUMMARY_CREATE`, `DEV_STANDUP_CREATE`: visible project → `{ kind: "PROJECT", projectId, state: "ACTIVE" }`; else `request.userId` and `lookupArchivedMembership(userId, projectId)` → `state: "ARCHIVED"`; else `null`.
- `LEAD_STANDUP_LIST`: visible project → `PROJECT`/`ACTIVE`; else `null`.
- `DEV_STANDUP_MINE_READ` (`SELF`): `request.userId` present and `requireMember(userId, projectId)` resolves → `{ kind: "STANDUP", projectId, ownerId: userId, state: "ACTIVE" }`; any throw → `null`. `requireMember` here is core's (it rejects archived projects and removed members).
