# T1: route identity and shared error seam

**Delivers:** Shared project route context/adapter, safe URL role resolution and fixed API errors.
**Satisfies:** F7,F8,N1,N2,E3,E7,E8,E14. **Depends on:** - **Wave:** 1 **Weight:** complex
**Review:** full (routing, roles and error security)

## Expected state
- `src/fe/app/[[...slug]]/page.tsx`, `src/fe/components/screen.tsx`, `src/fe/lib/nav.tsx`, `src/fe/lib/screens.ts` exist.
- `src/fe/components/canvas/Health.tsx` has its own UUID predicate.
- `src/fe/lib/api/http.ts` can expose arbitrary server messages.
- `src/fe/lib/api/project-mode.ts` does not exist.

## Objective
Create the exact UUID mode adapter and route context. Preserve project IDs in links, make excluded
views forbidden, map backend errors to fixed safe messages, and make Health use the shared seam.

## Rules that apply
- F7 Live UUID routes use the adapter; non-UUID routes remain prototype.
- N1/N2 The browser uses `apiFetch` only; no database imports or role bypasses.

## Contract
- UUID matching is case-insensitive RFC4122 v1-5; malformed/non-UUID ids use prototype mode.
- Route changes ignore prior responses and never show prototype data on live routes.
- 401 signs out and AuthGate replaces the page. Map 403 to `You do not have permission to view this.`,
  404 to `This project or task was not found.`, 409 to `This changed elsewhere. Reload before trying again.`,
  422 to `Check the highlighted fields.`, 429 to `Please wait before trying again.`, and network/5xx to
  `Something went wrong. Try again.`. Retain only codes `FORBIDDEN_ROLE,FORBIDDEN,NOT_FOUND,
  CONFLICT_VERSION,CONFLICT_STATE,VALIDATION_FAILED,RATE_LIMITED,NETWORK,INTERNAL,INTERNAL_ERROR`;
  preserve only bounded retry-after and field details, never arbitrary server messages.
- `resolve()` returns forbidden for role-excluded views, including direct mutation-dialog URLs.
