# T1: Core package and authorization seams

**Delivers:** `@agile/core` foundation, active membership checks, writable checks, and core-owned resource resolution | **Satisfies:** F1, F2, F7, N1, N3, E1, E6, E21, E23, E35 | **Depends on:** - | **Wave:** 1 | **Weight:** complex | **Review:** full (tenancy and authorization boundary)

## Expected state
- `src/be/core` does not exist.
- `src/be/contracts/src/frozen.ts` exports the frozen `Core` type.
- `src/be/api/src/deps.ts` contains fail-closed membership and resolver placeholders.

## Objective
Create the core workspace and its injected filtered-DB constructor. Implement `requireMember`, internal archived-membership probing, `assertWritable`, and a resolver registry for every core operation id without changing policy entries or frozen contracts.

## Rules that apply
- F1/F2/F7 — core is assignable to frozen `Core`; resolver data comes only from storage.
- SD1/SD4 — core owns membership; archived ordinary reads resolve as absent and write targets preserve 404/409 precedence.
- N1/N3 — use only the filtered request client; no raw SQL, maintenance client, or API table query.

## Contract
`requireMember(userId, projectId)` returns only for an active membership and otherwise throws a fresh `NotMember`. `resolveResource` returns `null` for malformed, missing, hidden, soft-deleted, or archived reads; archived write resources carry `state: "ARCHIVED"`. Map project/checkpoint/epic operations to frozen `PROJECT`, task/task-event operations to frozen `TASK`, member mutations to frozen `MEMBERSHIP`, and PROJECT_LIST to `PROJECT_SET`; assert every mapping without changing frozen contracts. Target role is supplied only after parsing by T5.

**Edge cases assigned**
| ID | Scenario | Expected behaviour (exact) |
|---|---|---|
| E1 | non-member or archived read | `NotMember`; no handler runs |
| E6 | cross-project child id | resolver returns `null` |
| E21 | forbidden DB path | import-boundary test fails |
| E23 | frozen interface consumer | core implementation remains assignable |
| E35 | malformed UUID path | resolver returns `null`, API later returns 404 |

## Steps
1. Run `ws task start T1`; write the failing membership, resolver, and frozen-interface tests.
2. Add the workspace and typed injected dependencies; do not modify `frozen.ts` or `policy.ts`.
3. Implement active membership and writable-state checks plus the internal archived probe.
4. Implement the explicit frozen-kind resolver mapping and malformed-id fail-closed behavior.
5. Run core tests, `npm run typecheck`, and `npm run lint` until green.
6. Write `handovers/T1.json`, commit with `Workstream: W5` and `Task: T1`, then run `ws task done`.
