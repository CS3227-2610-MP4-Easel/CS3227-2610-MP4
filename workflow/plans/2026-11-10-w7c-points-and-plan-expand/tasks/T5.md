## Objective
Under the proposal lock, one call claims every target epic with distinct versions; one call stores the model's tasks for every target whose claim is intact; one call marks claimed targets FAILED. Single-epic claims also return the rest of the plan. No model call, no row of another proposal touched.

## Rules that apply
- Lock order: `lockProposal` first, then epic rows ascending by index (`lockEpic`); decide from the re-read rows.
- Claim identity: a write to an epic row is allowed only while it is IN_PROGRESS at the version it was claimed at.
- The store types are mirrored in `pm/src/plan-flow.ts` by T6; do not import pm.
- `EXPAND_LEASE_MS` becomes 75,000 and applies to both the single and the bulk claim.

## Contract
```ts
// expand-store.ts [contract]
export const EXPAND_LEASE_MS = 75_000;
export type PlanContextEpic = { index: number; title: string; description: string; checkpointName: string | null; tasks: EpicTask[] | null };
// ClaimResult CLAIMED gains: others: PlanContextEpic[]  (every other epic, ascending index, read inside the claim transaction; tasks = the stored tasks when a non-empty array, else null)
// bulk-store.ts [contract]
export type PlanClaim = { index: number; title: string; description: string; checkpointName: string | null; claimedVersion: number };
export type PlanClaimResult = { kind: "NONE"; proposal: PlanProposal } | { kind: "CLAIMED"; projectId: string; sessionId: string; approach: string; targets: PlanClaim[]; done: PlanContextEpic[] };
export function claimPlanEpics(db: FilteredDbClient, i: { proposalId: string; actorId: string; version: number; now?: Date }): Promise<PlanClaimResult>;
export function storePlanEpics(db: FilteredDbClient, i: { proposalId: string; results: { index: number; claimedVersion: number; tasks: EpicTask[] }[]; flagged: boolean }): Promise<{ stored: number; skipped: number }>;
export function failPlanEpics(db: FilteredDbClient, i: { proposalId: string; claims: { index: number; claimedVersion: number }[]; error: string }): Promise<number>;
```
**claimPlanEpics.** One transaction: `guardEdit` (404 unknown or other creator or archived project; 409 `CONFLICT_STATE` unless PENDING; 409 `CONFLICT_VERSION`), then read all epic rows ascending. Any row live IN_PROGRESS (`isLive`) gives `ProposalError("CONFLICT_STATE")` before anything is written. Targets are rows whose status is PENDING, FAILED or IN_PROGRESS with an expired lease; `done` is every DONE row (as `PlanContextEpic` with its tasks). No target: after the transaction return `{ kind: "NONE", proposal }` with `proposal = await getProposalView(db, proposalId, actorId)` (null view: `ProposalError("NOT_FOUND")`). Otherwise: base = `1 + max(watermark, all epic versions)`; target k (0-based) gets version `base + k`; if the last is above 2,147,483,646 throw `ProposalError("CONFLICT_STATE")` and write nothing; write payload `epicVersionWatermark` = last; set each target `expansionStatus: "IN_PROGRESS"`, `leaseExpiresAt: now + EXPAND_LEASE_MS`, `error: null`, `version`; return `claimedVersion` per target, the proposal's `projectId`, `sessionId` and `approach` (string or empty).
**storePlanEpics.** One transaction: `lockProposal`; missing or not PENDING gives `ProposalError("CONFLICT_STATE")`. For each result ascending: read the epic under the proposal lock; skip without locking if missing, not IN_PROGRESS or the version differs. Otherwise `lockEpic` and recheck IN_PROGRESS and `version === claimedVersion`; write only if still matching (tasks as given, DONE, `error: null`, `leaseExpiresAt: null`, `version + 1`), else count it as skipped. Zero stored: throw `ProposalError("CONFLICT_STATE")` (rolls back, including `flagged`). When at least one stored and `flagged`, set the proposal `flagged: true`. The proposal `version` does not change.
**failPlanEpics.** One transaction: `lockProposal`; not PENDING returns 0. For each claim ascending, read under the proposal lock and skip stale or missing rows without locking; otherwise `lockEpic` and recheck the same guard before it becomes `expansionStatus: "FAILED"`, `error`, `leaseExpiresAt: null`, `version + 1`; returns how many were marked.
