## Objective

The runtime and the test binder expose the three new store functions. Exactly one `run` call per `expandAll` that has targets, none otherwise, never inside a transaction.

## Contract
```ts
// plan-flow.ts [contract]: mirrored types and additions
// PlanContextEpic and PlanTargetEpic are imported from "./sections.js" (T4 exports them; pm/src/index.ts re-exports both files, so a second exported declaration of the same name would not compile)
export type PlanClaim = { index: number; title: string; description: string; checkpointName: string | null; claimedVersion: number };
export type PlanClaimResult = { kind: "NONE"; proposal: PlanProposal } | { kind: "CLAIMED"; projectId: string; sessionId: string; approach: string; targets: PlanClaim[]; done: PlanContextEpic[] };
// ClaimResult CLAIMED gains: others: PlanContextEpic[]
// ProposalsApi gains:
claimPlanEpics(i: { proposalId: string; actorId: string; version: number; now?: Date }): Promise<PlanClaimResult>;
storePlanEpics(i: { proposalId: string; results: { index: number; claimedVersion: number; tasks: EpicTask[] }[]; flagged: boolean }): Promise<{ stored: number; skipped: number }>;
failPlanEpics(i: { proposalId: string; claims: { index: number; claimedVersion: number }[]; error: string }): Promise<number>;
// PlanFlow gains:
expandAll(i: { caller: Caller; proposalId: string; version: number }): Promise<PlanProposal>;
// PlanFlowDeps gains an optional logger; createPlanFlow's returned object must include expandAll (the PlanFlow type derives from it)
onExpandAll?: (e: { targets: number; written: number; skipped: number }) => void;
```
Call `deps.onExpandAll?.({ targets, written: stored, skipped })` after a successful store, and only counts (never titles or text) are passed. `runtime.ts` binds it to `console.info("PM_PROPOSAL_EXPAND_ALL", { targets, written, skipped })`.
**expandAll.** (1) `claimPlanEpics({ proposalId, actorId: caller.userId, version, now: clock.now() })`; errors through `mapProposalError`; `NONE` returns its `proposal` with no call. (2) `aiContext.assembleWith(caller, "PM_PLAN_EXPAND", claim.projectId, { query: bulkQuery(claim.targets) })`, then `buildBulkSections({ approach: claim.approach, targets, done: claim.done, assembled: assembled.sections })`, then `runModel` with `feature: "PM_PLAN_EXPAND"`, `output: { kind: "json", schema: bulkOutputSchema(targets.map(t => t.index)) }`, `inputHash("PM_PLAN_EXPAND", sections)`. (3) On any failure: `failPlanEpics({ proposalId, claims, error: code })` (a throw there counts as "marked"); if it returns 0 throw `PlanFlowError("CONFLICT_STATE", 409, "The proposal or project is no longer in a state that allows this.")`, else throw the mapped error. (4) On success: map `value.epics` to `{ index, claimedVersion, tasks }` using each target's `claimedVersion`, call `storePlanEpics({ proposalId, results, flagged: result.flagged })`; a `ProposalError` `CONFLICT_STATE` leaves the rows and is mapped (409); any other store error calls `failPlanEpics` with `INTERNAL` then maps. (5) Return `getProposal({ caller, proposalId })`.
**Single expansion.** `expandClaim` passes `others: claim.others` to `buildExpandSections` (used by `expandEpic` and `regenerateEpic`).
