## Contract
`[contract]` in `config.ts`:
```ts
/** A session opened for the value admits calls of every feature that maps to it (spec SD3); other features map to themselves. */
export const SESSION_FEATURE: Partial<Record<Feature, Feature>> = { PM_PLAN_EXPAND: "PM_PLAN_OUTLINE" };
```
`[impl]` in `sessions.ts` `assertUsable`: replace `row.feature !== feature` by a check that fails unless `row.feature === feature` or (when `feature` is an own key of `SESSION_FEATURE`) `row.feature === SESSION_FEATURE[feature]`. A session opened for `PM_PLAN_EXPAND` therefore still admits `PM_PLAN_EXPAND` calls (W2's E26 test relies on it); a `PM_PLAN_EXPAND` session still rejects `PM_PLAN_OUTLINE` calls. `regenerate` is unchanged (it uses `row.feature`). `open` caps are per session feature, unchanged.
