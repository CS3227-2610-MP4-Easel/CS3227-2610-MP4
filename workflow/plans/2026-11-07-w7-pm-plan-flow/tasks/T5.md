## Objective
A plan proposal and its epic rows are stored in one transaction; a proposal is read back as a `PlanProposal` whose `retrieved` titles and project names are resolved per viewer; resolvers give the policy gate the proposal's project.

## Rules that apply
- Filtered client only (`FilteredDbClient` from `@agile/db`); archived projects and their proposals are invisible.
- Proposal rows are never deleted. `ai_proposals.version` starts at 1 and changes only on approve and reject; `flagged` is set at insert here.
- `retrieved` in the payload holds ids only; titles and project names are looked up on every read for projects where the viewer is a member (ProjectMember row), through the filtered client; an id that no longer resolves is omitted.

## Contract
`[contract]` `errors.ts`: `export class ProposalError extends Error { constructor(readonly code: "NOT_FOUND" | "CONFLICT_STATE" | "CONFLICT_VERSION" | "FORBIDDEN_ROLE" | "INVALID_PLAN") }` (message = code).
`[contract]` `create.ts`:
```ts
export type CreateProposalInput = { projectId: string; creatorId: string; sessionId: string; flagged: boolean; approach: string;
  checkpoints: { name: string; targetDate: string }[]; retrieved: { source: "EPIC" | "TASK"; projectId: string; id: string }[];
  epics: { title: string; description: string; checkpointName: string | null }[] };
export async function createProposal(db: FilteredDbClient, input: CreateProposalInput): Promise<string>;  // returns the proposal id
```
One `db.$transaction`: read the project (`db.project.findFirst({ where: { id } })`; null -> `ProposalError("CONFLICT_STATE")`), insert `AiProposal` `{ projectId, kind: "PLAN", status: "PENDING", payload: { approach, checkpoints, retrieved }, sessionId, createdBy: creatorId, flagged }`, then `proposalEpic.createMany` with `index` 0..n-1, `contentHash` = sha256 hex of `title + "\n" + description + "\n" + (checkpointName ?? "")`, `expansionStatus` PENDING, `tasks` omitted.
`[contract]` `view.ts`: `export async function getProposalView(db, proposalId: string, viewerId: string): Promise<PlanProposal | null>` — null when the filtered client finds no row. Epics ordered by `index`; an `IN_PROGRESS` row whose `leaseExpiresAt` is earlier than now (strictly) is shown `PENDING`; lease equal to now stays `IN_PROGRESS`. Also export `toPlanEpic(row, now = new Date()): PlanEpic` (`expansion: { status, tasks, error }`) for T6.
`[contract]` `resolvers.ts`: `export function createProposalResolvers(db: FilteredDbClient): ResourceResolver`, used for endpoints 35, 37, 40 and 41; it reads `request.params.proposalId`, returns `null` for a non-uuid or unknown id, else `{ kind: "PROPOSAL", projectId, ownerId: createdBy, state: "ACTIVE" }`.
