## Objective
Approve creates the plan's checkpoints, epics, tasks and events in one transaction, idempotently; reject marks a PENDING proposal REJECTED; both close the session afterwards; every race has one winner.

## Rules that apply
- Lock-then-read (Shared context). Status check first, then version, then epics.
- `proposals` calls `core.applyPlan` inside its own transaction; it never writes domain tables.
- Session close happens after commit; a close failure is logged `console.warn("pm_session_close_failed", { sessionId })` and does not fail the request. If the session already left OPEN (abandoned), `close` changes nothing and that is accepted.
- `ai_proposals.version` rises by 1 only on approve and reject.

## Contract
`[contract]` `decide.ts`:
```ts
export type DecideDeps = { db: FilteredDbClient; core: Pick<Core, "applyPlan">; sessions: Pick<Sessions, "close"> };   // Core, Sessions from @agile/contracts
export async function approveProposal(deps: DecideDeps, input: { proposalId: string; version: number; actorId: string }): Promise<PlanApproval>;
export async function rejectProposal(deps: Omit<DecideDeps, "core">, input: { proposalId: string; version: number; actorId: string }): Promise<PlanProposal>;
```
`approveProposal` (one transaction): lock the proposal row (none -> `NOT_FOUND`); read proposal and epics; status `APPROVED` -> return `{ proposalId, status: "APPROVED", created: payload.applied }` whatever the body version (then call `close` again after the transaction); `REJECTED` or `SUPERSEDED` -> `CONFLICT_STATE`; `version !== input.version` -> `CONFLICT_VERSION`; any epic not `DONE` (an `IN_PROGRESS` row counts as not DONE) -> `CONFLICT_STATE`; build `PlanInput` from the proposal payload `checkpoints` and the epic rows in index order (`tasks` from the stored JSON); set `status` APPROVED, `appliedBy`, `appliedAt`, `payload = { ...payload, applied: countPlan(plan) }`, `version` + 1; `await core.applyPlan(tx, projectId, plan, actorId)`; map `INVALID_PLAN` and `CONFLICT_STATE` to `ProposalError("CONFLICT_STATE")`, `NotMember` to `ProposalError("NOT_FOUND")`, `FORBIDDEN_ROLE` to `ProposalError("FORBIDDEN_ROLE")`, and rethrow so the transaction rolls back. After commit: `sessions.close(sessionId, "ACCEPTED", actorId)`.
`rejectProposal`: lock; status not PENDING -> `CONFLICT_STATE` (checked before the version); version mismatch -> `CONFLICT_VERSION`; set REJECTED, `version` + 1; after commit `close(sessionId, "REJECTED", actorId)`; return `getProposalView`'s result for the actor.
