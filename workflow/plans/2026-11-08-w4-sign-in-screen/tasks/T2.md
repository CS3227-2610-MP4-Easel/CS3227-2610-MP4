## Objective

## Rules that apply

- SD12 - `/api/as` keeps today's behaviour in `prototype` mode but gets a same-origin `to` check.
- Rule six (source scan, T7) - no `'use client'` file may import `lib/auth/mode.ts`; do not add `'use client'` to it.

## Contract
`src/fe/lib/auth/mode.ts` [contract]:
```ts
export type AuthMode = 'firebase' | 'prototype' | 'unconfigured';
export const FIREBASE_KEYS = ['NEXT_PUBLIC_FIREBASE_API_KEY', 'NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN', 'NEXT_PUBLIC_FIREBASE_PROJECT_ID', 'NEXT_PUBLIC_FIREBASE_APP_ID'] as const;
export function authMode(env: Record<string, string | undefined>): AuthMode;
```
Each value is trimmed; an empty result counts as absent. `APP_TIER` is compared exactly (case-sensitive). Rules, first match wins:

| Condition | Mode |
|---|---|
| all four `FIREBASE_KEYS` present | `firebase` |
| `APP_TIER === 'preview'`, none of the four present, `VERCEL_ENV` (trimmed) `!== 'production'` | `prototype` |
| anything else | `unconfigured` |

`src/fe/app/api/as/route.ts` `GET(req)` [contract]:
- `authMode(process.env) !== 'prototype'` -> `new Response(null, { status: 404 })`, no cookie set or deleted.
- Otherwise as today (role cookie set for `pm`/`lead`/`dev`, deleted for `out`, redirect), except the target: `const u = new URL(to, req.url)`; use `u.pathname + u.search + u.hash` only when `to.startsWith('/')`, `to` contains no `\` and no `%5c`/`%5C`, and `u.origin === new URL(req.url).origin`; else `/projects`. `NextResponse.redirect` keeps its default status (307).
