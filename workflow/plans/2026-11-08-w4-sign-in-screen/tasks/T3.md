## Objective
One module owns every Firebase call, one owns hard navigation, and one owns every `/api` request: it attaches the ID token only to same-origin `/api/` paths, maps error bodies to `ApiError`, and starts sign-out on an authenticated 401.

`lib/auth/navigate.ts` [contract]: `export function hardNavigate(path: string): void` -> `window.location.assign(path)`.

`ApiError` [contract] moves to a new `lib/api/errors.ts` (`'use client'`) so `http.ts` and `index.ts` do not import each other; `index.ts` removes its class and adds `export { ApiError } from './errors';` plus `import { ApiError } from './errors';` for its own uses, so every existing import of `ApiError` from `lib/api` keeps working:
```ts
export class ApiError extends Error {
  status: number; details: { field: string; message: string }[]; requestId: string | null; retryAfterSeconds: number | null;
  constructor(public code: string, message: string, opts: { status?: number; details?: { field: string; message: string }[]; requestId?: string | null; retryAfterSeconds?: number | null } = {})
}
```
Defaults: `status` 0, `details` `[]`, `requestId` null, `retryAfterSeconds` null.

`lib/api/http.ts` [contract]: `export async function apiFetch<T>(path: string, init?: { method?: 'GET' | 'POST' | 'PATCH' | 'DELETE'; body?: unknown; auth?: boolean }): Promise<T>`
- Path check first: must match `/^\/api\/[A-Za-z0-9._~\-\/?=&%]*$/`; the path part (before any `?`) must contain no `%2f` or `%5c` (any case) and no `//` after `/api/`, and no `/`-separated segment of it may equal (case-insensitively) `.`, `..`, `%2e`, `.%2e`, `%2e.` or `%2e%2e`; else `throw new Error('apiFetch: path must be a same-origin /api/ path')` before `idToken` or `fetch`.
- `auth` defaults to true. If true: `const t = await idToken()`; null -> `throw new ApiError('UNAUTHENTICATED', 'Authentication is required.', { status: 401 })` with no request and no sign-out; else header `Authorization: Bearer ${t}`.
- `body !== undefined` -> `JSON.stringify(body)` with `Content-Type: application/json`. Method default `GET`.
- Call `fetch(path, { method, headers, body, redirect: 'error', credentials: 'same-origin' })`; a rejection -> `ApiError('NETWORK', 'Something went wrong.', { status: 0 })`.
- 2xx: 204 or empty text -> `undefined`; else `JSON.parse`; parse failure -> `ApiError('INTERNAL', 'Something went wrong.', { status })`.
- Non-2xx: if the text parses to `{ error: { code: string, message: string, details?, requestId? } }` -> `ApiError(code, message, { status, details, requestId, retryAfterSeconds })`; else `ApiError('INTERNAL', 'Something went wrong.', { status, retryAfterSeconds })`.
- `retryAfterSeconds`: header `Retry-After` matching `/^\d+$/` with value 1-3600 -> that integer, else null.
- Non-2xx 401 and `auth` true -> `signOutUser().catch(() => {})` before throwing. `auth: false` -> throw only.
