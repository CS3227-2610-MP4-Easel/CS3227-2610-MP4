## Contract
`components/live/sign-in.tsx` [contract] (`'use client'`, default export `SignIn()`, no props):
- Inputs: Email (`id="em"`, `type="email"`, `autoComplete="email"`), Password (`id="pw"`, `type="password"` or `"text"` when shown, `autoComplete="current-password"`).
- Show/Hide: a `<button type="button">` in place of the canvas "Show" span; label "Show" when hidden, "Hide" when shown; flips the password input type.
- Submit "Sign in": disabled while `session?.status === 'loading'` or a request is in flight (`useSession()` is typed nullable; read it with `?.`). While in flight: `aria-busy="true"` and label "Please wait…".
- On submit: `preventDefault`; clear the banner; `await signIn(email, password)`; on rejection set the banner to the error's `message` (or "Something went wrong." when the rejection has no string `message`).
- "New here? Create an account" is `<a href="/register">`.
