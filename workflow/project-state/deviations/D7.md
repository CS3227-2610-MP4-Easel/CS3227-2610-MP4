# D7 — Internal errors do not count towards the breaker (W2 close-out)

- **Date:** 2026-11-05
- **Workstream:** W2
- **Still live:** yes — the code still behaves this way

## What the Document Said

Spec api.md § Breaker update: every call ending `UPSTREAM_ERROR` adds one to the breaker.

## What Is True Instead, and Why

A provider error that is not an `UpstreamError` (for example a mock that throws, or a bug) is still recorded as `UPSTREAM_ERROR` but no longer counts, because the Attacker review showed one user's input could otherwise trip the breaker for everyone.

## Consequence

Real 5xx, network and timeout failures still count.
