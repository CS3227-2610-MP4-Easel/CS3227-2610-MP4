# D17 — Live settings reject short keys (W3)

- **Date:** 2026-11-07
- **Workstream:** W3
- **Still live:** yes — the code still behaves this way

## What the Document Said

The approved output specification ignored short secrets while live settings accepted them.

## What Is True Instead, and Why

Settings now reject keys shorter than eight characters, matching the guard's minimum.

## Consequence

A live key under eight characters fails settings validation.
