# D6 — Small interface adaptations (W2 T6, T7)

- **Date:** 2026-11-05
- **Workstream:** W2
- **Still live:** yes — the code still behaves this way

## What the Document Said

The W2 spec's interfaces for `createLlmGateway`, the usage queries and `run`.

## What Is True Instead, and Why

`createLlmGateway` takes two extra optional seams, `mockResponses` and `stateKeyPrefix` (test isolation); `usageSessions`, `usageSummary` and (after PR #14 review) `failureReason` take the tier as an explicit argument, and `failureReason` returns null for another tier's call; `run` throws `LLM_CALL_FAILED` (row finalised `UPSTREAM_ERROR`) when something throws after its row is written, a case the spec did not list.

## Consequence

No frozen interface changed.
