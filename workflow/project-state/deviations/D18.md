# D18 — The frozen `assemble` serves only features without required options (W6 SD4)

- **Date:** 2026-11-06
- **Workstream:** W6
- **Still live:** yes — the code still behaves this way

## What the Document Said

Contracts §5.2 promises `AiContext.assemble` for every feature.

## What Is True Instead, and Why

`DEV_SUMMARY` and `DEV_STANDUP` need item ids or a window that the frozen signature cannot carry, so for them `assemble` throws `INVALID_ASSEMBLE_INPUT` and features call `assembleWith`. The frozen type itself is unchanged. The operator chose to keep it and seek the PM's and Dev Lead's sign-off in the W6 PR (C60); signed off under AD-11 on 2026-11-07 (C59).

## Consequence

Contracts §5.2 needs a follow-up naming `assembleWith` as the entry point for every feature.
