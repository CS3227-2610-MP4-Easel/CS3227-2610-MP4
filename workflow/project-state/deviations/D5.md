# D5 — A W1 integration test fails under Prisma 7, left failing on purpose (W2 T1)

- **Date:** 2026-11-05
- **Workstream:** W2
- **Still live:** no — resolved 2026-11-06 (C29)

## What the Document Said

The suite passes with a database.

## What Is True Instead, and Why

`src/be/db/test/visibility-integration.test.ts:10` built `new PrismaClient({ datasourceUrl: url })`, an option Prisma 7 removed, so it failed with "Unknown property datasourceUrl" whenever `W1_INTEGRATION_DATABASE_URL` was set. CI sets no database, so it skipped there; the Prisma 7 merge (`9077725`) updated W4's tests but not this one. Not caused by W2. The operator chose to leave it failing (2026-11-05); the fix is the `PrismaPg` adapter pattern W4's tests use.

## Consequence

`npm test` with a database showed 1 failure until the fix. Resolved 2026-11-06 (C29): fixed on the W2 branch after the PR #14 review; the full suite passes.
