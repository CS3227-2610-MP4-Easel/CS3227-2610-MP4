# D3 — App-bound route registration (W1 route seam)

- **Date:** 2026-11-03
- **Workstream:** W1
- **Still live:** yes — the code still behaves this way

## What the Document Said

The design described `registerRoute(route)` as the public registration seam.

## What Is True Instead, and Why

The shipped form is `registerRoute(app, route, deps?)`, with a per-app registry; `createApiApp(deps)` registers the shared `ROUTES` list.

## Consequence

Non-public routes must be registered with dependencies, and downstream route modules append definitions to `ROUTES`.
