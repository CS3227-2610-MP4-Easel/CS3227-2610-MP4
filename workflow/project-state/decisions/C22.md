## Decision

All source code lives under `src/`; the frontend is `src/fe` and backend packages are under `src/be`.

## Why

The project requirement is a dedicated source root, and PR #6 established the frontend handover at `src/fe`.

## Rejected Alternatives

- Keep backend packages under the old top-level paths — leaves the monorepo split across incompatible layouts.
