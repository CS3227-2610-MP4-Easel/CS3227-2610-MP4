# C32 — Use GitHub reviews as the sensitive-path approval source

- **Date:** 2026-11-04.
- **Who asked:** operator (Dev Lead), choosing actual GitHub PR review verification.
- **Decision:** Sensitive-path PRs must have current exact-head `APPROVED` reviews from `@ludannnn` and the author-dependent human approver. The committed review artifact is supporting evidence only; the checker evaluates all paginated review records and treats the latest non-dismissed state as authoritative.
- **Why:** A JSON artifact committed by the PR can be forged or become stale. GitHub's review record is the authoritative source for reviewer identity and approval state.
