# C39 — Use a fixed bootstrap list for the first manifest rollout

- **Date:** 2026-11-04.
- **Who asked:** operator (Dev Lead), selecting Option 2.
- **Decision:** If the base branch lacks the sensitive-path manifest during the first W12 rollout, T6 uses a fixed list compiled into the checker and requires the head manifest to match exactly. Once the manifest exists on the base branch, the fallback is disabled.
- **Why:** This preserves one W12 merge while preventing the PR from selecting an arbitrary sensitive-path policy. The rejected alternatives were a temporary full ruleset bypass and a separate seed merge.
