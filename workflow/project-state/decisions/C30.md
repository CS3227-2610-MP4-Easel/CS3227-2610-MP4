# C30 — One CODEOWNER approval per PR

- **Date:** 2026-11-05.
- **Who asked:** Dev Lead, requesting the review rule return to one approval per PR.
- **Decision:** GitHub branch protection requires one CODEOWNER approval; the separate dual-review check is not required. Supersedes the dual-review portions of C31, C32, C33 and C34.
- **Why:** The Dev Lead requested the simpler review rule for the small team.
