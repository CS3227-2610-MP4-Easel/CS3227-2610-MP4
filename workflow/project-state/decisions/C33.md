# C33 — Use GitHub approvals without a committed artifact

- **Date:** 2026-11-04.
- **Who asked:** operator (Dev Lead), requesting the artifact-removal change.
- **Decision:** Sensitive-path CI requires only current exact-head GitHub `APPROVED` reviews from `@ludannnn` and the author-dependent human approver; it does not require a committed security-review JSON artifact.
- **Why:** The two GitHub reviews are the authoritative approval source, and removing the PR-controlled artifact reduces ceremony and eliminates a redundant evidence file. This material change requires renewed Gate 1 and Gate 2 approval.
