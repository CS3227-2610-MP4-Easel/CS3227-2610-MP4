# C24 — Remove the obsolete frontend scaffold

- **Date:** 2026-11-02
- **Who asked:** operator (Dev Lead)
- **Supersedes:** the old `apps/web` layout in the architecture
- **Superseded by:** —
- **Shapes area:** architecture/web.md
- **Binding (guardrails.md):** no

## Decision

The obsolete `apps/web` scaffold is removed; the maintained frontend is `src/fe`.

## Why

PR #6 supplies the frontend in `src/fe`, so retaining the old scaffold would create competing entry points.

## Rejected Alternatives

- Keep `apps/web` as a compatibility package — leaves an obsolete source tree and ambiguous ownership.
